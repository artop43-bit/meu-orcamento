# Mudanças rejeitadas pelo usuário

Não propor de novo sem o usuário pedir.

| O quê | Por quê |
|---|---|
| Pix "copia e cola" e QR Code gerados no site | Não funcionaram no uso real; não há integração com banco |
| Botão "Abrir no WhatsApp" | Abre só o WhatsApp Web, sem conversa; depende de serviço externo |
| Campo de telefone para cobrança | Só existia para o WhatsApp |
| "Compartilhar" do celular | Usuário quer só "Copiar mensagem" |
| IA no bot | Gera custo |
| ~~Oracle Pay As You Go~~ | Gera custo — **liberado em 14/11/2026**, só com recursos Always Free |
| Termo com cara de relatório (marca do app, e-mail, taxa equivalente) | Precisa ser documento para entregar |
| Extras do Dashboard & CRM: atualização automática de fontes (sem agendador), rotas sem tela (`/crm/hub/status`, `/sources/{id}/query`), extração de CPF/CNPJ dos PDFs | Não foram pedidos — tirados na revisão de 20/11/2026 |
| Firecrawl no produto (raspagem/busca na web) | Serviço externo, nuvem paga e o produto não tem IA (avaliado em 20/11/2026) |
| CLI-Anything | Sem uso: o projeto já é todo acessível por terminal (avaliado em 20/11/2026) |
| QR Code Pix / Pix Copia e Cola ou vínculo bancário na solução de Propostas & Documentos | Exige integração/custo ou configuração complexa cliente a cliente; manter apenas geração e gestão de documentos em PDF (20/11/2026) |
