# Modelo de checklist

Usado antes de qualquer mudança (ver [[Regras de trabalho com o Claude]]).

```markdown
**Checklist vX.Y.Z — <título curto>**

1. **<Área/tela>:** o que muda, em linguagem do usuário.
   - detalhe 1
   - detalhe 2
2. **<Área/tela>:** ...
3. **Testes:** quais testes novos/atualizados e o que garantem.
4. **Publicação:** fotos antes do PR; changelog; PR, CI, deploy e acompanhamento de 10 em 10 minutos.

Pontos para você decidir: (opções, com a recomendada primeiro)

Posso seguir?
```

Boas práticas:
- Listar também o que **sai** (não só o que entra).
- Avisar riscos/limitações honestamente (ex.: limite legal, dependência externa).
- Quando o usuário ajusta, reenviar o checklist inteiro revisado.
